# COFRAP — PoC Serverless OpenFaaSSystème de gestion de comptes utilisateurs avec génération automatique de mot de passe, QR code et 2FA, déployé en architecture serverless sur Kubernetes.**Sujet** : MSPR TPRE921 — Bloc 2 RNCP35584  **Stack** : K3s/Minikube + OpenFaaS + PostgreSQL + Python + React/Vite---## Architecture```React (Frontend) → Gateway OpenFaaS → 4 fonctions Python → PostgreSQL```| Namespace | Contenu ||---|---|| `openfaas` | Gateway, Prometheus, AlertManager, NATS || `openfaas-fn` | 4 fonctions Python || `data` | PostgreSQL (StatefulSet + volume 1 Go) |---## Prérequis### Backend- Linux (Ubuntu recommandé)- K3s **ou** Minikube (4 Go RAM minimum)- Helm 3- faas-cli- Docker + compte Docker Hub- Python 3.10+ avec `cryptography` et `pyotp`### Frontend- Node.js 18+- npm---## Lancement du backend### 1. Cloner le repo```bashgit clone https://github.com/mbidoyen/cofrap-poc.gitcd cofrap-poc```### 2. Lancer le script de démarrage```bashchmod +x start.sh./start.sh```Le script détecte automatiquement K3s ou Minikube et :- Installe Helm et faas-cli si absents- Déploie OpenFaaS- Déploie PostgreSQL avec le StatefulSet- Crée la table `users`- Lance le port-forward sur le port 8080- Crée les secrets OpenFaaS### 3. Builder et déployer les fonctions```bashcd functionsdocker loginfaas-cli template store pull python3-httpfaas-cli build -f stack.yamlfaas-cli push -f stack.yamlfaas-cli deploy -f stack.yaml```⚠️ **Important** : modifier `stack.yaml` pour remplacer `dockerazariel` par votre username Docker Hub.### 4. Vérifier```bashfaas-cli listkubectl get pods -n openfaas-fn```---## Lancement du frontend```bashcd frontend/mspr-2-frontendnpm installnpm run dev```Ouvrir `http://localhost:5173` dans le navigateur.⚠️ **Important** : modifier `vite.config.ts` pour pointer vers l'IP de votre VM :```typescripttarget: 'http://VOTRE_IP:8080'```---## Les 4 fonctions| Fonction | Méthode | Payload | Description ||---|---|---|---|| `create-account` | POST | `{"username": "jean.dupont"}` | Crée un compte complet (MDP + 2FA) || `generate-password` | POST | `{"username": "jean.dupont"}` | Régénère uniquement le MDP || `generate-2fa` | POST | `{"username": "jean.dupont"}` | Régénère uniquement le 2FA || `authenticate` | POST | `{"username": "...", "password": "...", "totp_code": "..."}` | Authentifie un utilisateur |---## Tests rapides```bash# Créer un comptecurl -s -X POST http://127.0.0.1:8080/function/create-account \  -H "Content-Type: application/json" \  -d '{"username": "test.user"}' | jq '.message'# Vérifier en basekubectl exec -it -n data postgres-0 -- psql -U cofrap_app -d cofrap \  -c "SELECT id, username, expired FROM users;"```---## Procédure de reprise après reboot```bash# 1. Port-forwardkubectl port-forward -n openfaas svc/gateway 8080:8080 \  --address 0.0.0.0 > /tmp/port-forward.log 2>&1 &# 2. Login OpenFaaSPASSWORD=$(kubectl -n openfaas get secret basic-auth \  -o jsonpath="{.data.basic-auth-password}" | base64 --decode)echo -n $PASSWORD | faas-cli login --username admin --password-stdin# 3. Vérifierfaas-cli list```---## Secrets nécessaires| Secret | Valeur par défaut | Description ||---|---|---|| `db-host` | `postgres.data.svc.cluster.local` | DNS interne PostgreSQL || `db-name` | `cofrap` | Nom de la base || `db-user` | `cofrap_app` | Utilisateur PostgreSQL || `db-password` | À définir | Mot de passe PostgreSQL || `fernet-key` | Généré automatiquement | Clé de chiffrement AES |⚠️ Ne jamais commiter les vraies valeurs des secrets sur GitHub.---## Limites identifiées- Connexion DB ouverte à chaque invocation → PgBouncer en production- Gateway en HTTP → Ingress Traefik + TLS en production  - 1 seul replica par fonction → autoscaling à configurer- Pas de rate limiting (hors périmètre sujet)## Images DockerLes images sont publiques sur Docker Hub.
